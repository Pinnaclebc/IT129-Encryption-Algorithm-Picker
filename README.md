# IT129 Encryption Algorithm Picker

## Description

A console-based Python menu for selecting encryption algorithm placeholders. This project was created for the IT129 college course at Mapua Malayan Colleges Laguna.

## Tech Stack

- Python 3

## Setup

1. Clone this repository.
2. Open a terminal in the project directory.
3. Run the program:

   ```powershell
   python main.py
   ```

The four encryption algorithm modules are currently placeholders and can be replaced with their implementations later.
